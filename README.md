# Отчёт

## 1. Выполненная работа

- Добавлена секция **Special Offers** с адаптивной вёрсткой.
- Реализована структура секции и оформление её элементов.
- Проверено отображение на разных разрешениях. При этом адаптивность уже существовавших секций сайта требует дополнительной доработки.
- Проведен анализ структуры основного компонента `App.svelte`.

## 2. Найденные проблемы

- **Видео на главном экране:** используется `preload="auto"`, а позиция воспроизведения меняется при каждом событии прокрутки. Это может создавать лишнюю нагрузку на CPU и вызывать рывки.
- **Большой компонент App.svelte:** разметка, стили, API-запросы, расчёты, анимации и обработчики событий находятся в одном файле.
- **Поиск и фильтры:** запрос отправляется при каждом изменении поисковой строки, расчёты и фильтрация выполняются внутри основного компонента.
- **Изображения:** некоторые контейнеры получают размеры только после загрузки изображений, что может вызывать смещение контента.
- **Адаптивность:** в стилях присутствуют фиксированные минимальные ширины, которые могут вызывать горизонтальную прокрутку на мобильных устройствах.
- **Очистка ресурсов:** необходимо проверить удаление обработчиков событий, таймеров и экземпляров сторонних библиотек при уничтожении компонентов.

## 3. Что необходимо улучшить

1. Оптимизировать обработчик прокрутки и работу фонового видео.
2. Добавить debounce для поиска и оптимизировать работу фильтров.
3. Заранее резервировать размеры изображений для предотвращения скачков вёрстки.
4. Исправить адаптивность существующих секций.
5. Разделить `App.svelte` на самостоятельные компоненты.
6. Вынести API-запросы в отдельные сервисы, а расчёты и фильтрацию — в отдельные модули.
7. Организовать корректную очистку обработчиков, таймеров и сторонних библиотек.

# Larch Quay

Landing page for the Larch Quay residential quarter.

## Requirements

- Node 24

## Setup

```
npm install
```

## Commands

- `npm run dev` starts the dev server on http://localhost:5173
- `npm run build` creates a production build in `dist`
- `npm run preview` serves the production build on http://localhost:4173
